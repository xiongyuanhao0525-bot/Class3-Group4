## 1. Article（文章表 blog_article）

| 字段名 | 数据类型 | 约束 | 说明 |
|---|---|---|---|
| id | INT | 主键，自增 | 文章编号 |
| title | VARCHAR(200) | 非空，唯一 | 文章标题 |
| body | LONGTEXT | 非空 | Markdown 正文 |
| pub_time | DATETIME | 非空，默认当前时间 | 发布时间 |
| status | CHAR(1) | 默认 'p' | 状态：d=草稿，p=已发布 |
| comment_status | CHAR(1) | 默认 'o' | 评论开关：o=开启，c=关闭 |
| type | CHAR(1) | 默认 'a' | 内容类型：a=文章，p=独立页面 |
| views | INT UNSIGNED | 默认 0 | 浏览量 |
| author_id | INT | 外键 → BlogUser.id，级联删除 | 文章作者 |
| category_id | INT | 外键 → Category.id，级联删除 | 所属分类 |
| article_order | INT | 默认 0 | 排序权重，越大越靠前 |
| show_toc | TINYINT(1) | 默认 0 | 是否显示文章目录 |
| slug | VARCHAR(60) | 自动生成 | URL 别名（由标题生成） |
| creation_time | DATETIME | 默认当前时间 | 创建时间 |
| last_modify_time | DATETIME | 默认当前时间 | 最后修改时间 |

> 关联：一篇文章通过中间表 article_tags 与多个 Tag 建立 **多对多** 关系。

## 5. Tag（标签表 blog_tag）

| 字段名 | 数据类型 | 约束 | 说明 |

## 主要表间关系

- BlogUser 1 ── N Article（一个用户写多篇文章）
- Category 1 ── N Article（一个分类下多篇文章）
- Category 1 ── N Category（自引用：父子分类）
- Article M ── N Tag（多对多，通过中间表）
- BlogUser 1 ── N Comment
- Article 1 ── N Comment
- Comment 1 ── N Comment（自引用：楼中楼回复）
- Comment 1 ── N CommentReaction（表情回应）
- BlogUser 1 ── N CommentReaction
