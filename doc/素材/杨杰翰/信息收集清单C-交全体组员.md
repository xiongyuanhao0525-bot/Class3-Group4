## 填写口径（三人以上统一，避免数据对不上）

1. **注释行数**：`git diff --numstat` 中新增的注释行数，口径为"模块级 docstring + 类级 + 方法级 + 带姓名标识的行内注释"，测试文件与 `__init__.py` 不计。
2. **受影响行数**：以 commit 为准，格式写 `新增 xx 行 / 删除 xx 行`；把 commit 号贴上来，汇总人可复核。
3. **维护要素**：从"新增功能 / 修改缺陷 / 改善可维护性 / 性能优化 / 用户体验"中选，一条写清"名称 + 做法 + 影响的文件"。
4. 所有数字必须能在仓库里复现（写清 commit 号或命令），不接受估计值。
