> **版本**: v2.1.0  
> **编写人**: 杨杰翰  
> **编写日期**: 2026-10-08  
> **说明**: 本数据字典详细描述了 DjangoBlog 博客系统的所有数据模型，包含字段名称、数据类型、业务含义和约束条件。

---

## 一、数据模型概览

DjangoBlog 项目包含 **12个数据模型**，分布在5个应用模块中：

| 模块 | 模型数量 | 模型名称 |
|------|----------|----------|
| accounts | 1 | BlogUser |
| blog | 6 | Article, Category, Tag, Links, SideBar, BlogSettings |
| comments | 2 | Comment, CommentReaction |
| oauth | 2 | OAuthUser, OAuthConfig |
| servermanager | 2 | commands, EmailSendLog |

## 二、详细数据字典

### 2.1 accounts 模块

#### 2.1.1 BlogUser（用户表）

**说明**: 自定义用户模型，继承自 Django 的 AbstractUser，用于存储博客系统用户信息。

| 序号 | 字段名称 | 字段代码 | 数据类型 | 长度 | 允许空 | 默认值 | 业务含义 | 约束说明 |
|------|----------|----------|----------|------|--------|--------|----------|----------|
| 1 | 主键 | id | AutoField | - | 否 | 自动递增 | 用户唯一标识 | 主键，自增 |
| 2 | 用户名 | username | CharField | 150 | 否 | - | 用户登录账号 | 继承自 AbstractUser，唯一 |
| 3 | 昵称 | nickname | CharField | 100 | 是 | 空字符串 | 用户显示昵称 | 可选，用于文章作者显示 |
| 4 | 邮箱 | email | EmailField | - | 是 | - | 用户邮箱地址 | 继承自 AbstractUser |
| 5 | 创建时间 | creation_time | DateTimeField | - | 否 | now() | 账户注册时间 | 自动记录，不可修改 |
| 6 | 最后修改时间 | last_modify_time | DateTimeField | - | 否 | now() | 账户信息最后修改时间 | 自动更新 |
| 7 | 用户来源 | source | CharField | 100 | 是 | 空字符串 | 账户创建来源 | 如：本地注册、GitHub登录、微博登录等 |
| 8 | 密码 | password | CharField | 128 | 否 | - | 用户密码 | 继承自 AbstractUser，Django 自动加密存储 |

**索引信息**:
- 主键索引：id (AutoField)
- 排序索引：按 id 降序排列

**关系说明**:
- 一对多：1个用户 → 多篇文章 (Article.author)
- 一对多：1个用户 → 多条评论 (Comment.author)
- 一对多：1个用户 → 多个OAuth用户 (OAuthUser.author)
- 一对多：1个用户 → 多个评论反应 (CommentReaction.user)

### 2.2 blog 模块

#### 2.2.1 Article（文章表）

**说明**: 存储博客文章的核心数据模型，支持普通文章和独立页面两种类型。

| 序号 | 字段名称 | 字段代码 | 数据类型 | 长度 | 允许空 | 默认值 | 业务含义 | 约束说明 |
|------|----------|----------|----------|------|--------|--------|----------|----------|
| 1 | 主键 | id | AutoField | - | 否 | 自动递增 | 文章唯一标识 | 主键，自增 |
| 2 | 标题 | title | CharField | 200 | 否 | - | 文章标题 | 必填，唯一，最大200字符 |
| 3 | 正文 | body | MDTextField | - | 否 | - | 文章Markdown正文内容 | 使用 django-mdeditor 字段，支持富文本 |
| 4 | 发布时间 | pub_time | DateTimeField | - | 否 | now() | 文章正式发布时间 | 用于文章排序和展示 |
| 5 | 状态 | status | CharField | 1 | 否 | 'p' | 文章状态 | 'd'=草稿(Draft)，'p'=已发布(Published) |
| 6 | 评论状态 | comment_status | CharField | 1 | 否 | 'o' | 评论开关状态 | 'o'=开启评论(Open)，'c'=关闭评论(Close) |
| 7 | 内容类型 | type | CharField | 1 | 否 | 'a' | 文章类型 | 'a'=普通文章(Article)，'p'=独立页面(Page) |
| 8 | 浏览量 | views | PositiveIntegerField | - | 否 | 0 | 文章浏览次数 | 正整数，用于统计和排行榜 |
| 9 | 作者 | author | ForeignKey | - | 否 | - | 文章作者关联 | 外键指向 BlogUser，级联删除 |
| 10 | 排序权重 | article_order | IntegerField | - | 否 | 0 | 文章排序权重 | 数值越大越靠前，结合发布时间排序 |
| 11 | 显示目录 | show_toc | BooleanField | - | 否 | False | 是否展示文章目录TOC | True=显示，False=隐藏 |
| 12 | 分类 | category | ForeignKey | - | 否 | - | 文章所属分类 | 外键指向 Category，级联删除 |
| 13 | 标签 | tags | ManyToManyField | - | 是 | - | 文章关联标签 | 多对多关系，可为空 |
| 14 | 创建时间 | creation_time | DateTimeField | - | 否 | now() | 文章创建时间 | 自动记录 |
| 15 | 最后修改时间 | last_modify_time | DateTimeField | - | 否 | now() | 文章最后修改时间 | 自动更新 |

**索引信息**:
- 主键索引：id
- 唯一索引：title (标题唯一)
- 组合索引：type + status + pub_time (优化列表查询)
- 组合索引：status + views (优化热门文章查询)
- 组合索引：author + status + type (优化作者文章查询)
- 组合索引：category + status (优化分类查询)

**关系说明**:
- 多对一：多篇文章 → 1个作者 (Article.author → BlogUser)
- 多对一：多篇文章 → 1个分类 (Article.category → Category)
- 多对多：多篇文章 ↔ 多标签 (Article.tags ↔ Tag)
- 一对多：1篇文章 → 多条评论 (Article.comment_set)

**枚举值说明**:
```python
STATUS_CHOICES = (
    ('d', 'Draft - 草稿'),
    ('p', 'Published - 已发布')
)

COMMENT_STATUS = (
    ('o', 'Open - 开启评论'),
    ('c', 'Close - 关闭评论')
)

TYPE = (
    ('a', 'Article - 普通文章'),
    ('p', 'Page - 独立页面')
)
```

| 5 | 排序索引 | index | IntegerField | - | 否 | 0 | 分类排序权重 | 数值越大越靠前 |
| 6 | 创建时间 | creation_time | DateTimeField | - | 否 | now() | 分类创建时间 | 自动记录 |
| 7 | 最后修改时间 | last_modify_time | DateTimeField | - | 否 | now() | 分类最后修改时间 | 自动更新 |

**索引信息**:
- 主键索引：id
- 唯一索引：name
- 排序索引：按 index 降序排列

**关系说明**:
- 自关联：多对一（子分类 → 父分类）
- 一对多：1个分类 → 多篇文章 (Article.category)

### 2.3 comments 模块

#### 2.3.1 Comment（评论表）

**说明**: 存储用户对文章的评论信息，支持嵌套回复。

| 序号 | 字段名称 | 字段代码 | 数据类型 | 长度 | 允许空 | 默认值 | 业务含义 | 约束说明 |
|------|----------|----------|----------|------|--------|--------|----------|----------|
| 1 | 主键 | id | AutoField | - | 否 | 自动递增 | 评论唯一标识 | 主键，自增 |
| 2 | 评论内容 | body | TextField | 300 | 否 | - | 评论正文内容 | 最大300字符 |
| 3 | 创建时间 | creation_time | DateTimeField | - | 否 | now() | 评论发表时间 | 自动记录 |
| 4 | 最后修改时间 | last_modify_time | DateTimeField | - | 否 | now() | 评论最后修改时间 | 自动更新 |
| 5 | 评论者 | author | ForeignKey | - | 否 | - | 评论用户关联 | 外键指向 BlogUser，级联删除 |
| 6 | 所属文章 | article | ForeignKey | - | 否 | - | 所属文章关联 | 外键指向 Article，级联删除 |
| 7 | 父评论 | parent_comment | ForeignKey | - | 是 | NULL | 父评论（用于嵌套） | 自关联，外键指向自身，空表示顶级评论 |
| 8 | 是否显示 | is_enable | BooleanField | - | 否 | False | 评论审核状态 | False=待审核，True=已通过审核显示 |

**索引信息**:
- 主键索引：id
- 组合索引：article + parent_comment + is_enable (优化评论列表查询)
- 组合索引：is_enable + id (优化侧边栏评论查询)
- 排序索引：按 id 降序排列

**关系说明**:
- 多对一：多条评论 → 1个用户 (Comment.author → BlogUser)
- 多对一：多条评论 → 1篇文章 (Comment.article → Article)
- 自关联：多对一（子评论 → 父评论）
- 一对多：1条评论 → 多个反应 (Comment.reactions)

### 2.4 oauth 模块

#### 2.4.1 OAuthUser（第三方用户表）

**说明**: 存储通过第三方平台（GitHub、Google等）OAuth登录的用户信息。

| 1 | 主键 | id | AutoField | - | 否 | 自动递增 | OAuth用户唯一标识 | 主键，自增 |
| 2 | 关联用户 | author | ForeignKey | - | 是 | NULL | 关联的本地用户 | 外键指向 BlogUser，可为空（新用户未绑定） |
| 3 | OpenID | openid | CharField | 50 | 否 | - | 第三方平台OpenID | 用于识别第三方平台用户，唯一 |
| 4 | 昵称 | nickname | CharField | 50 | 否 | - | 第三方昵称 | 从第三方平台获取的昵称 |
| 5 | 访问令牌 | token | CharField | 150 | 是 | NULL | OAuth访问令牌 | 用于调用第三方API |
| 6 | 头像URL | picture | CharField | 350 | 是 | NULL | 用户头像地址 | 第三方平台返回的头像URL |
| 7 | 平台类型 | type | CharField | 50 | 否 | - | OAuth平台类型 | 见枚举值说明 |
| 8 | 邮箱 | email | CharField | 50 | 是 | NULL | 用户邮箱 | 从第三方平台获取的邮箱 |
| 9 | 元数据 | metadata | TextField | - | 是 | NULL | 其他OAuth信息 | 存储第三方返回的其他用户信息JSON |
| 10 | 创建时间 | creation_time | DateTimeField | - | 否 | now() | 首次登录时间 | 自动记录 |
| 11 | 最后修改时间 | last_modify_time | DateTimeField | - | 否 | now() | 信息最后更新时间 | 自动更新 |

**索引信息**:
- 主键索引：id
- 唯一索引：openid + type (第三方平台OpenID唯一)
- 排序索引：按 creation_time 降序排列

**关系说明**:
- 多对一：多个OAuth用户 → 1个本地用户 (OAuthUser.author → BlogUser)

**枚举值说明**:
```python
TYPE = (
    ('weibo', '微博'),
    ('google', 'Google'),
    ('github', 'GitHub'),
    ('facebook', 'Facebook'),
    ('qq', 'QQ')
)
```

### 3.2 关系详细说明

| 关系类型 | 源模型 | 目标模型 | 说明 |
|----------|--------|----------|------|
| 1:N | BlogUser | Article | 1个用户可发布多篇文章 |
| 1:N | BlogUser | Comment | 1个用户可发表多条评论 |
| 1:N | BlogUser | OAuthUser | 1个用户可绑定多个第三方账号 |
| 1:N | BlogUser | CommentReaction | 1个用户可对多条评论进行反应 |
| N:1 | Article | Category | 多篇文章属于1个分类 |
| N:M | Article | Tag | 1篇文章可有多个标签，1个标签可关联多篇文章 |
| 1:N | Article | Comment | 1篇文章可有多条评论 |
| 1:N | Category | Category | 自关联，父分类包含多个子分类 |
| 1:N | Comment | Comment | 自关联，支持嵌套评论 |
| 1:N | Comment | CommentReaction | 1条评论可有多个用户反应 |
