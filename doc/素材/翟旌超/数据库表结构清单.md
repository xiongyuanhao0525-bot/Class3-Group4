## 三、核心业务表结构（逐表 `DESC` 结果）

### 3.1 `blog_article` —— 文章表（文章模块核心表）

`DESC blog_article;` ：

| 字段名 | 类型 | 允许空 | 键 | 默认值 | 额外 | 字段说明 |
| --- | --- | --- | --- | --- | --- | --- |
| `id` | int | NO | PRI | NULL | auto_increment | 主键，文章 ID |
| `title` | varchar(200) | NO | UNI | NULL | | 文章标题（全局唯一） |
| `body` | longtext | NO | | NULL | | 正文内容，Markdown 原文（`MDTextField`） |
| `pub_time` | datetime(6) | NO | | NULL | | 发布时间 |
| `status` | varchar(1) | NO | MUL | NULL | | 状态：`d`=草稿 / `p`=发布，默认 `p` |
| `comment_status` | varchar(1) | NO | | NULL | | 评论开关：`o`=打开 / `c`=关闭，默认 `o` |
| `type` | varchar(1) | NO | MUL | NULL | | 类型：`a`=文章 / `p`=独立页面，默认 `a` |
| `views` | int unsigned | NO | | NULL | | 阅读量，默认 0 |
| `article_order` | int | NO | | NULL | | 排序值（越大越靠前），默认 0 |
| `show_toc` | tinyint(1) | NO | | NULL | | 是否显示目录，默认 0 |
| `author_id` | bigint | NO | MUL | NULL | | 外键 → `accounts_bloguser.id`，作者 |
| `category_id` | int | NO | MUL | NULL | | 外键 → `blog_category.id`，所属分类 |
| `creation_time` | datetime(6) | NO | | NULL | | 创建时间（继承自 `BaseModel`） |
| `last_modify_time` | datetime(6) | NO | | NULL | | 最后修改时间（继承自 `BaseModel`） |

**索引（`SHOW INDEX` 真实结果）**：主键 `id`；唯一索引 `title`；4 个组合索引：

| 索引名 | 字段 | 用途 |
| --- | --- | --- |
| `idx_type_status_pub` | type, status, pub_time | 优化列表查询 |
| `idx_status_views` | status, views | 优化热门文章查询 |
| `idx_author_status_type` | author_id, status, type | 优化作者文章查询 |
| `idx_category_status` | category_id, status | 优化分类查询 |

**外键**：`author_id → accounts_bloguser(id)`、`category_id → blog_category(id)`，删除行为均为 `CASCADE`（作者/分类被删，其文章一并删除）。

### 3.2 `blog_category` —— 分类目录表（自关联树）

| 字段名 | 类型 | 允许空 | 键 | 默认值 | 额外 | 字段说明 |
| --- | --- | --- | --- | --- | --- | --- |
| `id` | int | NO | PRI | NULL | auto_increment | 主键，分类 ID |
| `name` | varchar(30) | NO | UNI | NULL | | 分类名（唯一） |
| `slug` | varchar(60) | NO | MUL | NULL | | URL 短名（由 name 经 uuslug 生成） |
| `index` | int | NO | | NULL | | 排序值，默认 0 |
| `parent_category_id` | int | YES | MUL | NULL | | 自关联外键 → `blog_category.id`，上级分类；顶级分类为 NULL |
| `creation_time` | datetime(6) | NO | | NULL | | 创建时间 |
| `last_modify_time` | datetime(6) | NO | | NULL | | 最后修改时间 |

**索引**：主键 `id`；唯一索引 `name`；普通索引 `slug`、`parent_category_id`。
**外键**：`parent_category_id → blog_category(id)`（自关联，1:N 树形结构，`CASCADE`）。

### 3.4 `blog_article_tags` —— 文章-标签中间表（M:N）

| 字段名 | 类型 | 允许空 | 键 | 默认值 | 额外 | 字段说明 |
| --- | --- | --- | --- | --- | --- | --- |
| `id` | bigint | NO | PRI | NULL | auto_increment | 主键，中间表自增 ID |
| `article_id` | int | NO | MUL | NULL | | 外键 → `blog_article.id` |
| `tag_id` | int | NO | MUL | NULL | | 外键 → `blog_tag.id` |

**索引**：主键 `id`；唯一索引 `(article_id, tag_id)`（防重复打标）；普通索引 `tag_id`。
**外键**：`article_id → blog_article(id)`、`tag_id → blog_tag(id)`（均由 Django 自动生成，`CASCADE`）。
**关系**：文章 ↔ 标签为 **M:N**（一篇文章多个标签，一个标签多篇文章），当前真实数据 8 篇文章共 18 条打标记录。

### 3.5 `comments_comment` —— 评论表（自关联回复）

| 字段名 | 类型 | 允许空 | 键 | 默认值 | 额外 | 字段说明 |
| --- | --- | --- | --- | --- | --- | --- |
| `id` | bigint | NO | PRI | NULL | auto_increment | 主键，评论 ID |
| `body` | longtext | NO | | NULL | | 评论正文 |
| `is_enable` | tinyint(1) | NO | MUL | NULL | | 是否通过审核/启用，默认 0（待审核） |
| `article_id` | int | NO | MUL | NULL | | 外键 → `blog_article.id`，被评论的文章 |
| `author_id` | bigint | NO | MUL | NULL | | 外键 → `accounts_bloguser.id`，评论人 |
| `parent_comment_id` | bigint | YES | MUL | NULL | | 自关联外键 → `comments_comment.id`，上级评论；顶层评论为 NULL |
| `creation_time` | datetime(6) | NO | | NULL | | 创建时间 |
| `last_modify_time` | datetime(6) | NO | | NULL | | 最后修改时间 |

**索引**：主键 `id`；普通索引 `article_id`、`author_id`、`parent_comment_id`；组合索引 `idx_art_parent_enable(article_id, parent_comment_id, is_enable)`、`idx_enable_id(is_enable, id)`。
**外键**：`article_id → blog_article(id)`、`author_id → accounts_bloguser(id)`、`parent_comment_id → comments_comment(id)`（自关联，`CASCADE`）。
**关系**：文章 ↔ 评论 **1:N**；评论 ↔ 评论 **1:N**（自关联实现「盖楼」式嵌套回复）。

### 3.6 `comments_commentreaction` —— 评论 Emoji 反应表

| 字段名 | 类型 | 允许空 | 键 | 默认值 | 额外 | 字段说明 |
| --- | --- | --- | --- | --- | --- | --- |
| `id` | bigint | NO | PRI | NULL | auto_increment | 主键 |
| `reaction_type` | varchar(10) | NO | | NULL | | Emoji 类型：👍👎❤️😄🎉😕🚀👀（共 8 种） |
| `created_at` | datetime(6) | NO | | NULL | | 反应时间（`auto_now_add`） |
| `comment_id` | bigint | NO | MUL | NULL | | 外键 → `comments_comment.id` |
| `user_id` | bigint | NO | MUL | NULL | | 外键 → `accounts_bloguser.id`，点赞人 |

**索引**：主键 `id`；唯一索引 `(comment_id, user_id, reaction_type)`（同一用户对同一评论的同一 Emoji 只能点一次）；组合索引 `idx_comment_reaction(comment_id, reaction_type)`。
**外键**：`comment_id → comments_comment(id)`、`user_id → accounts_bloguser(id)`（`CASCADE`）。
**关系**：评论 ↔ 用户 通过本表构成 **M:N**（点赞关系表）。

> 说明：`DESC` 输出的 `Comment` 列在本库中为**空**——因为 models.py 里字段说明用的是 `_('xxx')` 延迟翻译（`gettext_lazy`），Django 迁移不会把翻译后的中文写进 MySQL 的列注释，中文标签存在于 `locale/zh_Hans/LC_MESSAGES/django.po` 与 Django Admin 界面（如「作者」「分类目录」「上级评论」）。所以本清单的「字段说明」列是我依据 `models.py` + `django.po` 一一对照补全的，属于**对 `DESC` 结果的注释补充，不是数据库里的原始内容**，避免误导。
