# 模块功能说明（交杨杰翰 · 维护报告）

> 成员：王鑫悦（wxy_branch）｜模块：servermanager + plugins｜字数见下方统计（≤150 字）

本人负责 servermanager 与 plugins 两个模块。① servermanager 新增异常告警邮件通道：按告警指纹在合并窗口内聚合重复报警、在限频窗口内限制发信次数，接入 ChatGPT 调用与运维命令执行异常，避免同一故障刷屏邮件。② 图片懒加载插件：非首图以 data-src 存真实地址、内联 SVG 骨架占位，由 IntersectionObserver 进入视口回填，并加 onerror 失败兜底图。③ SEO 插件：补全 Twitter/X 卡片标签（文章页大图卡片、列表页摘要卡片），并在页面 head 暴露 sitemap 入口。配套补充了两模块单元测试。
